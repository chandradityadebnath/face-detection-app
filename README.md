# 📷 Real-Time Face Detection App

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python)
![OpenCV](https://img.shields.io/badge/OpenCV-Computer%20Vision-green?logo=opencv)
![License](https://img.shields.io/badge/License-MIT-brightgreen)

This is a beginner-friendly Python project that uses OpenCV to detect faces in real time through a webcam. This project was built as part of my early practice before college years to strengthen my Python programming skills and explore computer vision basics.

## Features included in here

- Real-time face detection from your webcam
- Visual bounding boxes around detected faces
- Simple keyboard controls to stop the app
- Lightweight and easy to run locally

## Project Purpose

This project was created during my early learning journey as a way to practice Python and get hands-on experience with image processing and computer vision. It reflects my interest in building simple, practical applications while improving my programming fundamentals.

## Requirements

- Python 3.8+
- OpenCV

## Installation

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   cd face-detection-app
   ```

2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the following command:

```bash
python face_detection_app.py
```

Press `a` or `q` to stop the webcam feed.

## Example

When the app starts, your webcam will open and detected faces will be highlighted with a green rectangle.
